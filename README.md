# 🧼 Delux Palm Cleaning Service Website

🌐 **Live Website:** https://deluxpalm.com/

---

## 🚀 Project Overview

Delux Palm is a modern and fully dynamic cleaning service website designed to streamline service booking and improve customer experience.
The platform allows users to explore services, calculate costs, and book appointments بسهولة through an intuitive interface.

---

## ✨ Key Features

* **Advanced Booking System**
  Users can book cleaning services directly from the website with a smooth and user-friendly appointment system.

* **Service Packages**
  Multiple cleaning packages such as Deep Cleaning and Weekly Cleaning are available for different customer needs.

* **Dynamic Cost Calculator**
  Customers can estimate service costs based on room count or area size.

* **Fully Responsive Design**
  Optimized for mobile, tablet, and desktop devices.

* **Testimonial Section**
  Displays customer reviews to build trust and credibility.

* **Google Maps Integration**
  Easy navigation to the business location.

---

## 🛠️ Tools & Technologies

* **CMS:** WordPress
* **Page Builder:** Elementor Pro
* **Plugins:** Crocoblock (JetEngine, JetBooking)
* **Forms:** WPForms / Elementor Forms
* **Styling & Animation:** Custom CSS, GSAP
